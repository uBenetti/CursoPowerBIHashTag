# Power BI

Repositório destinado ao armazenamento dos **estudos, exercícios, práticas e projetos desenvolvidos durante meu aprendizado em Power BI**, seguindo o curso de Power BI da **Hashtag Treinamentos**.

Este repositório tem como objetivo registrar minha evolução no aprendizado de **análise e visualização de dados**, reunindo exercícios práticos e dashboards desenvolvidos ao longo do curso.

Além de acompanhar o conteúdo das aulas, pretendo utilizar os conhecimentos adquiridos para aplicar conceitos de análise de dados em **projetos pessoais e acadêmicos**, buscando compreender melhor como transformar dados em informações úteis para tomada de decisões.

---

## Sobre o curso

O estudo aborda conceitos fundamentais do **Microsoft Power BI**, começando pela importação e organização de dados e avançando para tratamento, análise e visualização das informações.

Entre os principais conteúdos estudados estão:

- Importação de dados;
- Tratamento e transformação de dados;
- Power Query;
- Organização e relacionamento entre tabelas;
- Modelagem de dados;
- Criação de medidas e indicadores;
- Fórmulas e DAX;
- Gráficos e visualizações;
- Filtros e segmentações;
- Interação entre elementos;
- Construção de dashboards;
- Análise e interpretação de dados.

> **Curso:** Curso Básico de Power BI  
> **Plataforma:** YouTube  
> **Instituição:** Hashtag Treinamentos  
> **Área:** Análise e Visualização de Dados

## Conteúdos estudados

### 📥 Importação e tratamento de dados

- Importação de diferentes fontes de dados;
- Organização das bases;
- Limpeza de dados;
- Alteração de tipos de dados;
- Substituição de valores;
- Criação de colunas;
- Colunas condicionais;
- Combinação de tabelas;
- Atualização das bases.

### 🔄 Power Query

Utilização do **Power Query** para preparar e transformar os dados antes de utilizá-los nas análises.

O objetivo é compreender como criar processos de tratamento que possam ser reaplicados automaticamente quando os dados forem atualizados.

### 🗂️ Modelagem de dados

- Relacionamento entre tabelas;
- Organização das informações;
- Tabelas de fatos e dimensões;
- Estruturação das bases para análise.

### 📊 Fórmulas e indicadores

Estudo das principais funções utilizadas no Power BI para criação de métricas e indicadores.

Entre elas:

- `SUM`
- `AVERAGE`
- `CALCULATE`
- Divisões e percentuais;
- Medidas personalizadas;
- Indicadores de desempenho.

### 📈 Visualização de dados

Criação e personalização de:

- Gráficos;
- Cartões;
- Tabelas;
- Matrizes;
- Segmentações de dados;
- Indicadores;
- Dashboards interativos.

## Projetos

Além dos exercícios realizados durante o curso, este repositório também poderá receber **projetos próprios**, desenvolvidos com o objetivo de aplicar os conhecimentos de Power BI em situações mais próximas de projetos reais.

A ideia é utilizar dados provenientes de projetos acadêmicos e pessoais para praticar:

**Dados → Tratamento → Modelagem → Análise → Visualização → Insights**

Dessa forma, o aprendizado não ficará limitado aos exemplos apresentados durante o curso.
